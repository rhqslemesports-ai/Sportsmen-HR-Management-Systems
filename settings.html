🔐 Security & Privacy Notice

This system handles sensitive personnel information. This frontend prototype stores all data in your browser (localStorage) and performs authentication client-side for demonstration only. Before any real deployment you must connect a secure server-side backend with proper authentication, encrypted storage, access control and audit logging. Do not enter real personal data into this prototype.
